## Example - Firefox Browser Add-on

[TableToCsv](https://addons.mozilla.org/en-US/firefox/addon/tabletocsv1/?utm_source=addons.mozilla.org&utm_medium=referral&utm_content=search) is a Firefox Browser Add-on available on the Firefox marketplace for free.

It enables HTML tables to be exported to CSV files.

Tables can be cycled through, such that they are highlighted with a thick border and scrolled automatically into view.
